# GPXDash

GPXDash is a self-hosted server and browser dashboard for storing, viewing, organizing, and sharing GPS tracks.

## Website and documentation

Visit **[dashapps.app/gpxdash](https://dashapps.app/gpxdash/)** for information and user guides. Documentation is maintained on the website, not duplicated in this repository.

## Installation files

- [docker-compose.yaml](docker-compose.yaml)
- [.env](.env)

Keep both files in the same folder. The supplied `.env` contains defaults and placeholders; keep your populated copy private.

## Support

Report problems through [GitHub Issues](https://github.com/marcoue/GPXDash-Support/issues). Do not include passwords, private sharing links, or location data in public reports.
